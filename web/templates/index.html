What this tool does: Populates an OnWatch system with data from config.yaml (KV parameters, system settings, groups, accounts, watch list, devices, inquiries, etc.). After an OnWatch upgrade, use Validate to verify the data is still correct.

Workflow:

  1. Ensure Config Status shows a valid config and set the correct IP and version (2.6 or 2.8).
  2. Click Run Population to populate the OnWatch system. A data_inserted YAML file is saved for later validation.
  3. After upgrading OnWatch, select the data_inserted file from the dropdown and click Validate to check that data survived the upgrade.

Page sections:

  • 1 · Run – Populate the system, or Validate after an upgrade. Enter your name so the saved snapshot is easy to find later (e.g. john_data_inserted_2026-02-16_12-00-00.yaml).
  • Target OnWatch system – The IP and version you're about to run against. Click Preview config.yaml to see the full dataset.
  • Saved snapshots – Every population run saves a snapshot of what actually went in. Validate against these after an upgrade. Click a filename to preview its contents.
  • Run progress / Results – Live progress of the current run and a summary of the latest one, including any manual checks required.
